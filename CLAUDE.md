## Project Overview

Jekyll-based GitHub Pages academic website for Xiangjun Tang (Postdoc Fellow at KAUST). Built on the [academic-homepage](https://github.com/luost26/academic-homepage) template with custom publication and showcase automation.

## Commands

```bash
# Install dependencies
bundle install

# Local development server
bundle exec jekyll serve

# Generate publication markdown from BibTeX files in assets/files/publications/
python markdown_generator/pubsFromBib.py

# Generate showcase index from _showcase/ folder contents
python markdown_generator/showcase_generator.py
```

## Architecture

### Content Data Flow

**Publications**: BibTeX files in `assets/files/publications/` → `pubsFromBib.py` → individual markdown files in `_publications/` with YAML front matter → Jekyll renders paper homepages and list entries.

**Showcase**: Content folders in `_showcase/` (novel/, travel/, media/) → `showcase_generator.py` → `_data/showcase_content.yml` → Jekyll renders the Showcase page. The script auto-generates markdown files for media-only folders.

### Configuration Files

- `_config.yml` — Jekyll config, collections definition, plugin settings
- `_data/profile.yml` — Personal info (name, position, bio, social links)
- `_data/display.yml` — Controls which sections appear on homepage
- `_data/navigation.yml` — Navigation bar pages
- `_data/authors.yml` — Author name → link mapping for publication co-authors

### Content Collections

- `_publications/` — Auto-generated by `pubsFromBib.py`; each file is one paper with YAML front matter (title, date, abstract, links, authors, teaser image, video)
- `_projects/` — Project entries
- `_news/` — News/updates for homepage
- `_showcase/` — Multimedia content (travel logs, writings, galleries)

## Publication Workflow

Each paper lives in its own folder under `assets/files/publications/<FolderName>/`. After editing, run `python markdown_generator/pubsFromBib.py` to regenerate `_publications/`.

### Files per paper folder

| File | Required | Description |
|------|----------|-------------|
| `citation.txt` | **Yes** | BibTeX entry — source of title, authors, year, venue |
| `extra.json` | No | External links: `"Arxiv"`, `"Video"`, `"Code"`, `"Project"`, etc. |
| `content.md` | No | Body content rendered on the paper homepage (abstract, etc.) |
| `teaser.*` | No | Any file with `teaser` in the name becomes the cover image |
| `main.pdf` | No | Auto-generates a "Paper" link |
| `appendix.pdf` | No | Auto-generates a "Supplementary" link |

### Key details

- BibTeX type in `citation.txt` determines venue field: `@article` uses `journal`, `@inproceedings` uses `booktitle`
- If the first author is `Xiangjun Tang`, the paper is marked `selected: true` (highlighted on homepage)
- `extra.json` keys are capitalized and truncated at `_` (e.g. `"video_url"` → `"Video"`)
- Link display order is fixed: Paper → Arxiv → Project → Supplementary → Video → Code
- To add a new author's homepage link, edit the `authors_info` dict in `markdown_generator/pubsFromBib.py`

### Key Assets

- `assets/css/global.css` — Custom styles
- `assets/js/semantic_scholar_citation_count.js` — Live citation count fetching
- `assets/files/` — Paper PDFs and supplementary materials
- `assets/images/` — Profile photo, paper teasers, gallery images
